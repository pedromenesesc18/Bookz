# Bookz 📚

App de celular pra catalogar livros: **lidos** (por ano e mês, com nota em estrelas), **lendo**, **quero ler** e **estante** (livros físicos ainda não lidos).

- Busca de livros com capa (Google Books / Open Library)
- Funciona offline e pode ser instalado na tela inicial
- Dados salvos no próprio aparelho, com backup em arquivo (menu ⋮)

## Publicar
Settings → Pages → Source: *Deploy from a branch* → `master` / `(root)`.

## Instalar no iPhone
Abra o link no Safari → Compartilhar → **Adicionar à Tela de Início**.
